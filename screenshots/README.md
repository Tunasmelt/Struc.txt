## Adding Screenshots

To add real screenshots:

1. Run the development server: `npm run dev`
2. Navigate to `http://localhost:3000`
3. Use your operating system's screenshot tool (Windows: Win+Shift+S, Mac: Cmd+Shift+4)
4. Save screenshots to this directory with the names above
5. Update the README.md if you add additional screenshots
